**Sobre o projeto:**

  Este projeto consiste em um site desenvolvido para apresentar e exibir a linha de motos da marca Harley-Davidson, destacando seus modelos, visuais e especificações de forma interativa e intuitiva.

**Estrutura do projeto:**

  A organização dos arquivos foi feita com base em boas práticas de estruturação no GitHub para garantir clareza e fácil navegação:
  
**HTML**: Arquivo principal de entrada da aplicação, contendo a estrutura base do site.

**CSS**: Contém as folhas de estilo para a personalização visual e layout das páginas.
